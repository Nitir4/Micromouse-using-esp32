The hardware of the micromouse contains (hopefully) :
1) ESP32
2) TB6612FNG motor driver
3) MPU6050
4) Buck Converter
5) Sharp IRs 
6) N20 Motors with Encoders
7) Battery



The file for the connections will be added as soon as i finish working on it.

There is also a standalone C++17 simulator in `micrmouse_simulator/` with file-loaded mazes, ASCII visualization, and sample algorithms for testing micromouse logic off-hardware.
